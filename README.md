# 🅰️ A++ Language Extensions & Math Library

<img width="1254" height="1254" alt="изображение" src="https://github.com/user-attachments/assets/b2a64927-80eb-4d3c-9a25-47c3f8d51015" />

Компактная математическая библиотека и набор базовых алгоритмов для стекового языка программирования **A++**. 
Библиотека предоставляет проверенные низкоуровневые подпрограммы для выполнения арифметических операций, сравнений и работы с памятью/стеком.
- **Чистый и компактный код:** Минимум инструкций, высокая скорость выполнения.
- **Безопасный старт:** Автоматический пропуск определений функций (`jmp math`) для предотвращения ошибок выполнения (`Stack empty`).
- **Стековая архитектура:** Полноценная работа с командами манипуляции стеком (`dup`, `swap`, `drop`, `over`).
