# A++ Language Extensions & Math Library


Компактная математическая библиотека и набор базовых алгоритмов для стекового языка программирования **A++**. 

Библиотека предоставляет проверенные низкоуровневые подпрограммы для выполнения арифметических операций, сравнений и работы с памятью/стеком.

---

## Особенности

- **Чистый и компактный код:** Минимум инструкций, высокая скорость выполнения.
- **Безопасный старт:** Автоматический пропуск определений функций (`jmp math`) для предотвращения ошибок выполнения (`Stack empty`).
- **Стековая архитектура:** Полноценная работа с командами манипуляции стеком (`dup`, `swap`, `drop`, `over`).

---

## Содержимое библиотеки (`math.app`)

| Функция | Входные данные | Выходные данные | Описание |
| :--- | :--- | :--- | :--- |
| `cube` | `x` | `x^3` | Возведение числа в куб |
| `square` | `x` | `x^2` | Возведение числа в квадрат |
| `fact` | `n` | `n!` | Вычисление факториала (рекурсивное) |
| `abs` | `x` | `\|x\|` | Модуль числа |
| `min` | `a, b` | `min(a, b)` | Минимальное из двух чисел |
| `max` | `a, b` | `max(a, b)` | Максимальное из двух чисел |
| `mod` | `a, b` | `a % b` | Остаток от деления |

---

## Быстрый старт

### Использование библиотеки в проекте

Подключите файл `math.app` и вызывайте нужные функции через `call`:

Добавьте путь до app.exe в `PATH` и пропишите где находится файл: app <имя файла>.app  

```a++
#include "math.app"

-- Пример: вычисление остатка от деления 17 % 5
17;
5;
call mod;
print; -- Выведет 2

-- Пример: вычисление факториала 5!
5;
call fact;
print; -- Выведет 120

halt;
```
